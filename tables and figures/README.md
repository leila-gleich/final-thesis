# Unified Tables and Figures Catalog
## Evaluating Predictive Techniques to Model Stochastic Airport Passenger Flow (MSAA / Gleich 700B)

This dedicated directory serves as the **single consolidated home** for all presentation tables, companion Excel workbooks, and visual figures across the thesis. It resolves version ambiguity by grouping assets into distinct, intuitive categories:

```
tables and figures/
├── appendix/      <- Master Appendix tables (A.1 to N.1) & Appendix diagram figures
├── methodology/   <- Methodology tables, schema definitions, and model architecture figures
└── results/       <- Empirical Results tables (Ch. 4 & 5) and performance figures
```

### Directory Structure & Master Workbooks
- **`appendix/`**: Contains `appendix_tables.xlsx` (all 30 canonical appendix tables formatted per APA 7 with clickable Table of Contents) and reference diagram figures.
- **`methodology/`**: Contains `methodology-tables.xlsx` and exhibits covering airport selection, data pipelines, schema architectures, and modeling workflows.
- **`results/`**: Contains `thesis_tables.xlsx` (all Chapter IV & V tables: Table 4.1 through 4.11, Table 5.1 through 5.4, and Dual-Track Decision Policy) along with empirical charts and radar diagrams.
